# AW09 — algebrization

Scott Aaronson and Avi Wigderson, “Algebrization: A New Barrier in Complexity
Theory,” *Theory of Computing* 5, 1–54 (2009); STOC 2008 preliminary version.

- Primary PDF: https://eccc.weizmann.ac.il/eccc-reports/2008/TR08-005/Paper.pdf
- Author PDF: https://www.scottaaronson.com/papers/alg.pdf
- Accessed: 2026-08-10
- Consumed claim: oracle access together with low-degree extensions captures a
  barrier that includes many arithmetization-based techniques and separates
  worlds relevant to central complexity questions.
- Scope control: failure to algebrize is necessary for the covered routes, not
  sufficient for correctness.
