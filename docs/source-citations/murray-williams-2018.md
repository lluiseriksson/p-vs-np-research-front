# MW18 — easy witnesses for NP and NQP

Cody D. Murray and R. Ryan Williams, “Circuit Lower Bounds for
Nondeterministic Quasi-polytime from a New Easy Witness Lemma,” STOC 2018;
*SIAM Journal on Computing* 49(5) (2020).

- DOI: https://doi.org/10.1137/18M1195887
- Author PDF: https://people.csail.mit.edu/rrw/easy-witness-nqp.pdf
- Accessed: 2026-08-10
- Consumed claim: Theorem 1.1 gives, under its GAP-C-UNSAT algorithm premise,
  `for all k, NTIME[n^(c k^4/epsilon)] notsubseteq C-SIZE[n^k]`.
- Scope control: the language witnessing noncontainment may depend on `k`; the
  theorem does not state that one NP language lacks all polynomial-size
  circuits.
