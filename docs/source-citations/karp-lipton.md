# KL82 — Turing machines that take advice

Richard M. Karp and Richard J. Lipton, “Turing Machines that Take Advice,”
*L'Enseignement Mathématique* 28 (1982), 191–209; result announced in 1980.

- Archive: https://www.e-periodica.ch/digbib/view?pid=ens-001%3A1982%3A28%3A%3A71
- Accessed: 2026-08-10
- Consumed claim: `NP subseteq P/poly` implies collapse of the polynomial
  hierarchy to its second level.
- Scope control: using the contrapositive requires an independently proved
  non-collapse, which is not available.
