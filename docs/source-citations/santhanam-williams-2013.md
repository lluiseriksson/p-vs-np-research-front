# SW13 — medium uniformity

Rahul Santhanam and Ryan Williams, “On Medium-Uniformity and Circuit Lower
Bounds,” IEEE Conference on Computational Complexity (2013), 15–23.

- DOI: https://doi.org/10.1109/CCC.2013.40
- Author PDF: https://people.csail.mit.edu/rrw/WeakUniformityCCC.pdf
- Accessed: 2026-08-10
- Consumed claim: for every fixed `k`, P is not contained in P-uniform
  `SIZE(n^k)`; the hard language can depend on `k`.
- Scope control: generator-uniform circuits are weaker adversaries than
  arbitrary non-uniform circuits, so this is not `P notsubseteq P/poly`.
