# COOK — official P versus NP statement

Stephen A. Cook, “The P versus NP Problem,” Clay Mathematics Institute problem
description.

- Primary URL: https://www.claymath.org/wp-content/uploads/2022/06/pvsnp.pdf
- Accessed: 2026-08-10
- Consumed claim: P asks whether every nondeterministic polynomial-time
  language has a deterministic polynomial-time algorithm; if an NP-complete
  language is in P, then `P=NP`.
- Scope control: average-case, real/complex-number models, and non-uniform
  variants are not substituted for the standard Turing-machine statement.
