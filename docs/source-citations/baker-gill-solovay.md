# BGS75 — relativization

Theodore Baker, John Gill, and Robert Solovay, “Relativizations of the
P =? NP Question,” *SIAM Journal on Computing* 4(4), 431–442 (1975).

- DOI: https://doi.org/10.1137/0204037
- Accessed: 2026-08-10
- Consumed claim: recursive oracles exist relative to which P equals NP and
  relative to which P differs from NP.
- Scope control: this blocks uniformly relativizing proof schemas; it does not
  prove the unrelativized classes equal or differ.
