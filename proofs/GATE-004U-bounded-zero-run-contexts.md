# GATE-004U-BOUNDED-ZERO-RUN-CONTEXTS — dense finite blocks force loss

**Label: NO-GO**

## Falsifiable theorem attempted

Attempted claim: exact SAT-gamma agreement on common-inner-length compact DNF
cores under every context generated by an arbitrarily dense concatenation of
a fixed finite neutral-block alphabet forces positive diagonal joint-quotient
loss.

More generally, the attempted theorem concerns any context family with
maximum zero-run length `rho(P)`. It is falsifiable by an agreeing total
function with nonpositive loss.

## Counterexample

LEMMA-050 partitions the outer region into

`m=floor(P/(rho(P)+1))`

disjoint consecutive windows of width `rho(P)+1`. Their positive OR clauses
are all one on every required context. Conjoin them to the canonical DNF core
base `H(r,u)` of exact size `K`.

The resulting agreeing total function has exact size
`K+(rho+1)m`, quotient at least `(rho+2)m`, and diagonal loss at most `K-m`.
Whenever `m>K`, the loss is negative.

For arbitrary concatenations of the ten ENC-022 blocks, `rho=7` even across
block boundaries. Thus linear block count still leaves `floor(P/8)` disjoint
width-eight clauses and negative loss for the usual small-context base.

## Structural conclusion

Unbounded block count is not enough. A context-only defense must also satisfy

`floor(P/(rho(P)+1))<=K(P)`,

equivalently it must permit zero runs of length roughly `P/K(P)` or larger,
unless broader syntax interactions invalidate the isolated outer predicate.
This is a necessary escape from this method, not a sufficient loss theorem.

Full GATE-004U remains open because it includes variable DNF cores and is not
confined to a fixed finite outer block alphabet.
