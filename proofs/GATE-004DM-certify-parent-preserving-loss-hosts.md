# GATE-004DM — certify parent-preserving loss hosts

**Label: EXPLORATORY**

LEMMA-218 caps residual restriction losses by carrier orientation. LEMMA-219
and NG-161 show that loss membership alone does not make those gates reusable
in the unrestricted parent.

## Falsifiable theorem

For every refined minimum endpoint with positive aligned circuit deficit,
construct enough physical hosts from the oriented residual loss union and
external regions such that, for each host set:

1. every unrestricted outgoing occurrence is named;
2. retargeting the hosts to the aligned certificate preserves every direct
   exterior consumer function across all four pair codes, or all changed
   consumers belong to a jointly replaced region;
3. the host sets are disjoint and exclude `{g,h}` and prior charges; and
4. the total certified hosts cover `D_b^DAG`, or the rewrite gives strict
   size or `W,Q,R_0` descent.

The theorem is falsified by a refined minimum endpoint whose residual loss
gates all have indispensable unmasked parent consumers, whose external regions
supply insufficient joint saving, and which admits no descent. Raw,
no-aligned-DAG, and incomparable branches remain explicit.
