# Formalization boundary

There is currently no `FORMALLY VERIFIED` terminal-critical mathematics.

The first formal targets, once stable, are encoding-neutral bookkeeping lemmas:
uniform polynomial time implies polynomial circuit size, polynomial many-one
reductions preserve `P/poly`, and the exponent-ratio padding lemma. A formal
artifact must report all axioms and may not encode the desired lower bound as an
axiom, typeclass field, oracle, or opaque constant.
